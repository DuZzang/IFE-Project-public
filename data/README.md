# 데이터 안내

이 폴더에는 연구 데이터를 넣지 않았다. 이 문서는 어떤 입력이 필요할 수 있는지 설명하는 용도다. 자료를 다운로드하거나 이 저장소에 추가하라는 지시는 아니다.

## 필요한 입력의 종류

| 입력 | 역할 | 현재 상태 |
|---|---|---|
| 교수님 제공 주식 자료 | 프로젝트의 종목군 및 가격 관련 입력 | 미포함. 수업·교수님 이용 조건 확인 필요 |
| CRSP 일별·월별 자료 | 주식 수익률, 위험 추정과 상장폐지 관련 보조 처리 | 원자료 및 종목별 파생물 미포함. 소속 기관·제공자 조건 확인 필요 |
| 팩터 및 기준지수 자료 | 신호 추정 또는 비교 기준 | 미포함. 각 제공자의 출처·이용 조건 확인 필요 |
| CNN 이미지·라벨, 모델 가중치 | CNN 학습·점수 생성 또는 기존 점수 사용 | 미포함. 제공자 및 팀의 권리·이용 조건 확인 필요 |
| 중간 신호 및 결과물 | 포트폴리오 계산 및 기존 결과 비교 | 미포함. 원천 자료와 파생물의 사용 범위 확인 필요 |

상장폐지 수익률 보조표는 교수님 자료를 바탕으로 하더라도 CRSP 월별 수익률과 상장폐지 정보를 결합해 만들어진 종목별 파생 데이터다. CRSP를 제외한 자유로운 공유 자료로 취급하지 않는다.

## 사용과 재현

분석을 다시 수행하려면 실행할 코드별 입력 목록과 필요 환경을 확인한 후, 정당한 접근 권한이 있는 사람이 해당 자료를 허용된 위치에 준비해야 한다. 데이터 접근 조건과 입출력 경로를 확인하기 전에는 실행 가능하다고 단정하지 않는다. 원자료·파생물을 저장하거나 외부 서비스에 올릴 수 있는지는 비공개 저장소를 포함해 학교·제공자의 조건을 확인해야 한다.

이 사본에는 데이터가 없으므로 전체 분석을 재현할 수 없다. 포함된 `SOURCE_MANIFEST.csv`는 코드 파일 경로와 해시를 나열한 목록이며 연구 데이터가 아니다.
