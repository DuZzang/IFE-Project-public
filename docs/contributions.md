# 팀 작업과 기여

> 기존 기여도 기록과 제출 묶음을 참고했다. 파일별 최초 작성자와 수정 범위 전체는 추가 확인 중이다.

## 팀 작업

금융공학개론 4인 팀이 CNN·금융 신호, 결합 포트폴리오, 위험 관리와 평가 및 제출 자료를 나누어 진행했다. 팀원의 초기 코드와 분석 초안을 바탕으로 전체 흐름을 통합하고 수정·검토했다.

## 내가 맡은 역할

IVOL·CNN을 담당하고, 팀 분석의 통합과 결과 검토, 팀 공유·발표 자료 조정을 맡았다. 상장폐지 수익률 반영의 필요성을 제시하고 필요한 자료를 제공했으며, 반영되지 않은 부분을 수정했다. 각 기여의 구체적인 파일 범위와 검증 절차는 추가 확인이 필요하다.

## 팀원과 AI의 기여

생성형 AI는 일부 코드·계산·문서 초안 작성을 도왔고, 나는 문제 제기와 수정·검토, 분석 통합을 수행했다. AI가 수행한 구현 전체를 내가 직접 작성한 것으로 표현하지 않는다. 여러 AI에 검증을 요청한 사실과 실제 확인된 검증 절차는 구분한다.

기존 제출 문서는 `src/alt_combination.py`, `src/alt_combination_core.py`, `tests/test_alt_combination.py`를 팀원 작성 코드로 구분한다. 파일별 세부 수정 이력과 외부 저작물의 사용 조건은 확인 중이다.

## 추가 확인 사항

- 파일별 직접 수정·판단 내용과 해당 버전
- 팀원 및 AI의 세부 기여와 필요한 출처 표기
- 수업 자료와 외부 라이브러리·사전학습 모델·데이터의 이용 조건
