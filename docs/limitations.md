# 한계와 확인할 사항

> 다음은 기존 제출·인수인계 문서에 기재된 내용과 현재 사본의 범위다. 이번 정리에서는 새 학습, 백테스트, 데이터 검증 또는 결과 재현을 수행하지 않았다.

## 평가와 해석

- 기존 제출 설명상 2005–2019년 평가 구간에서 전략을 선택하고 일부 민감도를 비교했다. 동일한 표본의 선택·비교 결과는 독립 테스트로 확인한 최적 성과가 아니다.
- 거래비용, 포트폴리오 구성, 위험 관리, 유동성 및 시장 상황의 가정은 분석마다 다를 수 있다. 원본 결과와 동일한 기간·지표·투자 조건을 확인하기 전에는 수치를 직접 비교하지 않는다.
- 2020년 스트레스 검토는 기존 제출 설명상 CNN을 제외한 세 신호 결과다. 네 신호의 독립 평가로 해석하지 않는다.

## 상장폐지 수익률

기존 보조표는 교수님 자료와 CRSP 월별 수익률 및 상장폐지 플래그를 결합했다. 후속 인수인계 문서에는 일부 `G/M/V` 플래그가 가리키는 지급액의 전부가 기존 수익률에 반영됐다고 볼 수 없다는 검토가 기록돼 있다. 이 정리 작업에서 CRSP 정의나 원자료를 재검증하지 않았으므로, 파일을 모든 상장폐지 수익률이 완전히 보정된 최종 정답으로 표현하지 않는다.

기존 제출 문서가 설명한 극단 수익률 스트레스 테스트는 가정에 따른 민감도 분석이며 누락된 실제 지급액을 복원했다는 뜻이 아니다.

## 실행·재현

교수님 자료, CRSP 원본·파생자료, 팩터·기준지수 입력, CNN 이미지·라벨, 모델 가중치, 중간·최종 결과물을 이 사본에 넣지 않았다. 스크립트별 필요 입력과 소프트웨어 환경을 확보·검증하기 전에는 코드 전체를 실행하거나 제출 결과를 재현할 수 없다.

일부 참고 스크립트의 PC 절대경로는 이 사본에서 프로젝트 루트 기준으로 바꿨다. 경로 변경이 실제 분석에 미치는 영향은 아직 실행 검증하지 않았다. 코드 문법 검사만으로 실행 결과의 정확성이나 성과가 확인되는 것은 아니다.

## 공개와 권리

코드·설명·데이터·결과물은 출처와 사용권을 각각 확인해야 한다. 원본·종목별 파생 데이터뿐 아니라 집계 결과·그림도 제공자 계약에 따른 확인이 필요하다. 두현이는 팀 프로젝트 코드의 공개를 목표로 하며 팀원과 AI의 기여를 구분해 기록한다. 수업 자료와 외부 라이브러리·사전학습 모델·데이터는 이용 조건과 공유 범위를 별도로 확인한다. 비공개 원격 저장소에 데이터를 저장하는 경우도 허용 여부를 별도로 확인한다. 권리 상태가 확인되기 전에는 임의의 공개 라이선스를 부여하지 않는다.
