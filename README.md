# 금융공학개론 팀 프로젝트 — 주식 포트폴리오 분석

> 팀 프로젝트 코드 정리본 · 공개 저장소이며 외부 데이터와 자료의 이용 조건은 별도로 확인합니다.

## 프로젝트 소개

금융공학개론 팀 프로젝트에서 CNN 기반 차트 신호와 모멘텀·베타·고유변동성(IVOL) 관련 신호를 조합해 주식 포트폴리오를 분석했다. 거래비용, 팩터, 기간, 현금 비교와 같은 추가 질문도 검토했다. 결과의 수익률·통계 수치는 이 코드 사본만으로 검증하지 않았으며, 이를 독립적인 투자 성과로 보장하지 않는다.

## 이 폴더의 출처와 범위

- 출처: 교수님 제출을 위해 만든 `IFE_Group7_Code_Data_QA_Verified_2026-11-01.zip`.
- 포함: 제출 ZIP의 Python 파일, 패키지 목록, IVOL 전략 설정. 경로 구조를 유지했다.
- 미포함: 교수님 제공 데이터, CRSP 원자료 및 종목별 파생 데이터, 데이터 압축파일, CNN 이미지·라벨, 모델 가중치, 결과표·그림·로그 및 기타 제출 자료.
- `SOURCE_MANIFEST.csv`는 입력 ZIP에 든 코드·설정 파일과 이 사본의 파일별 SHA-256 및 사본 변경 여부를 기록한다. 연구 데이터가 아닌 파일 목록이다.
- 예전 제출본과의 관계, 각 코드의 최종성, 전체 코드의 실행 가능성은 추가 확인이 필요하다. 2026-11-01 제출본에 없는 이전 버전의 코드는 자동으로 포함하지 않았다.

## 코드 지도

| 위치 | 역할 |
|---|---|
| `src/` | 신호 계산, CNN 관련 실행, 포트폴리오 구성·평가 스크립트 |
| `tests/` | 제출 묶음에 포함된 테스트 코드 |
| `handoff/ivol_combination/` | IVOL 신호와 결합 관련 코드·전략 설정 |
| `handoff/delisting_supplement/` | 교수님 자료와 CRSP 월별 자료를 이용한 상장폐지 수익률 보조표 생성 코드 |
| `qa_checks/` | 거래비용·팩터·기간·현금 관련 Q&A 분석 코드와 당시 확인용 스크립트 사본 |
| `requirements*.txt` | 제출 묶음에 기록된 Python 패키지 목록. 현재 환경과의 호환성은 확인하지 않았다. |

## 데이터와 실행 조건

**데이터가 빠져 있어 이 폴더만으로 전체 분석을 실행하거나 결과를 재현할 수 없다.** 코드에 따라 교수님 제공 주식 데이터, CRSP 일별·월별 데이터, 팩터 자료, 기준지수 자료, CNN 이미지·라벨, 기존 모델 또는 중간 결과가 필요할 수 있다. 실제 필요한 입력과 사용 권한은 실행할 스크립트별로 확인한다.

패키지 설치, 분석 실행, 모델 학습은 이 사본을 만드는 과정에서 수행하지 않았다. 기존 제출 문서에 적힌 검증 결과는 이번에 다시 재현한 결과가 아니다. `qa_checks/reference_results/`에는 참고용 스크립트만 있으며 당시 결과 데이터는 포함하지 않았다.

## 방법과 한계

- 기존 보정 코드는 교수님 자료에 CRSP 월별 정보를 결합해 수익률 보조표를 만든다. 해당 파일 자체와 원자료는 포함하지 않는다.
- 기존 후속 검토에서는 일부 상장폐지 유형에 대해 수익률이 완전히 반영되지 않을 수 있다고 보고했다. 이번에는 원자료나 관련 결과를 재검증하지 않았다.
- 기존 제출 문서에는 2005–2019년 구간에서 전략을 선택하고 일부 민감도를 비교한 내용이 있다. 이를 독립 표본에서 검증한 최적 성능으로 해석하지 않는다.

## 기여와 공개 전 확인

이 프로젝트는 팀으로 수행했다. 팀원이 만든 초기 초안을 바탕으로 전체 분석과 코드를 수정·통합하고 결과를 검토했다. 일부 코드와 문서 작성에는 생성형 AI의 도움을 받았다.

기존 제출 문서는 `src/alt_combination.py`, `src/alt_combination_core.py`, `tests/test_alt_combination.py`를 팀원 작성 코드로 구분한다. 파일별 구체적인 수정 범위는 추가 확인 중이며, 팀원·본인·AI의 기여를 구분해 기록한다. 외부에서 별도로 가져온 프로젝트 코드는 없으며, 사용한 라이브러리·사전학습 모델과 데이터의 이용 조건은 별도로 확인한다.

## 사본에서 바꾼 부분

`qa_checks/reference_results/` 아래 4개 스크립트의 특정 PC 사용자 절대경로만 이 폴더 위치를 기준으로 계산하도록 바꿨다. 대상과 파일별 원본·사본 해시는 `SOURCE_MANIFEST.csv`를 참고한다. 원본 ZIP 및 기존 프로젝트 코드는 변경하지 않았다. 이 경로 변경의 실제 분석 실행은 검증하지 않았다. 또한 `src/ppt_briefing.py`와 `src/plot_combination_deciles.py`의 출력 문구에서 교수님 표본과 관련된 대략적 종목 수만 제외했다. 해당 변경은 계산 로직에 영향을 주지 않는다.

## Git 정리 시 주의

`.gitignore`는 데이터·모델·결과물 및 압축파일이 실수로 포함될 가능성을 줄이기 위한 기본 장치다. 모든 민감 파일을 자동으로 판별하지 못하며, 코드 자체의 출처·개인정보·권한 확인을 대체하지 않는다. 커밋 전에는 포함될 파일을 확인하고, 원격 저장소의 공개 범위도 별도로 확인한다.
